# Stack

- **Bun and TypeScript.** Bun runs the code, scripts, tests, type checks (`bun check`), and package management, pinned by `.bun-version` and `packageManager`.
- **Lint and format.** Oxlint and oxfmt, run on staged files by lefthook and checked read-only in CI.
- **TypeScript for the engine, not Bend.** Bend 2 (v2.0.39, September 2026) was evaluated and rejected. Its targets are C, Metal, CUDA and a single-core JavaScript output; it has no WebAssembly, no documented way to call host JavaScript such as Durable Object storage or sqlite-wasm, and no Swift path. Its numbers are Nat, U32 and F32 only, so epoch milliseconds and sequence numbers do not fit, and strings are linked lists, so JSON handling is slow. The engine is SQL glue with no divide-and-conquer work to parallelize, so Bend's one strength does not apply. Its proof checker could state the protocol's invariants (idempotent replay, convergence) over a pure model, but a few TypeScript tests state the same and run everywhere the code runs.
