# Stack

- **Bun and TypeScript.** Bun runs the code, scripts, tests, type checks (`bun check`), and package management, pinned by `.bun-version` and `packageManager`.
- **Lint and format.** Oxlint and oxfmt, run on staged files by lefthook and checked read-only in CI.
- **TypeScript for the engine, Bend for the protocol's proofs.** Bend 2 (v2.0.39) cannot be the implementation: its targets are C, Metal, CUDA and single-core JavaScript, it has no Swift path, its numbers are Nat, U32 and F32, and the engine has no divide-and-conquer work for its parallelism. Its proof checker is adopted as an executable specification of the protocol. A prototype on 2026-10-24 modeled the server state, `apply`, `pull` and `applyPull` in 194 lines of Bend and proved four laws (replay idempotence, head monotonicity, pointwise convergence after a pull, and preservation of the convergence invariant under `apply`) in 417 lines of proof. `bend PROOF.bend` ran in 80 ms, and six deliberate mutations of the model each turned it red. `bend sync.bend -o sync.mjs` emits an ES module that Bun imports, and a 20-write random run produced conformance vectors in 8 ms. The model is the oracle the TypeScript core is tested against, never the shipped code. Caveats measured in the prototype: proofs hardcode the model's internal term shapes, so a refactor of the model costs a proof re-alignment even when every law still holds; the checker reports only the first failing def; `--verdict`, the Lean-checked kernel run, passed on the same proofs once Lean 4.34.0 was installed: 12.3 s on the first run, which builds the BendTT kernel into `~/.bend/bendtt` (4.7 MB, placed under the home directory even with `BEND_HOME` set), then 0.11 s warm. A mutated model fails the verdict in 0.06 s.
- **Lean through elan.** `elan-init.sh -y --no-modify-path --default-toolchain leanprover/lean4:v4.34.0` installs Lean into `~/.elan` and edits no shell profile; add `~/.elan/bin` to `PATH` where `bend --verdict` runs. CI needs the same toolchain, pinned to the version Bend names in its error message when Lean is missing.
